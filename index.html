Importation Pronote (Établissement d'origine)

Pour affiner l'analyse par établissement d'origine :
  1. Rendez-vous sur votre client Pronote (Menu Ressources > Élèves).
  2. Assurez-vous que la colonne Étab. d'origine est bien affichée dans la grille.
  3. Sélectionnez tous les élèves inscrits dans une classe, puis copiez les données.
  4. Collez le contenu (Ctrl+V) dans la zone à droite.

Traitement des Fichiers PDF & Publipostage

Réorganise les fiches DEPP et génère les archives pour le publipostage (Portail DEPP).

💡 Assistant Publipostage (Thunderbird)

Pour envoyer automatiquement les PDF générés aux familles, utilisez le logiciel Thunderbird avec l'extension Mail Merge (ou sa fonction de publipostage native). L'outil ci-dessous génère tout ce dont vous avez besoin.

  • Assurez-vous d'avoir importé le fichier Siècle (Onglet Configuration) pour récupérer les emails.
  • L'archive ZIP contiendra directement un fichier de base de données au format .csv prêt à être utilisé dans Thunderbird.
  • Important : Extrayez bien le fichier .csv ET les PDF dans le même dossier sur votre ordinateur.
